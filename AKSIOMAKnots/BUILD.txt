Build (Qt 6.5+ recommended, with the "Qt Quick/OpenGL" modules installed)

  cmake -S . -B build -DCMAKE_PREFIX_PATH=<path to Qt, e.g. C:/Qt/6.8.0/msvc2022_64>
  cmake --build build --config Release
  run build/AKSIOMAKnots   (Windows: build/Release/AKSIOMAKnots.exe, run windeployqt first)

Or: open CMakeLists.txt in Qt Creator and pick a Qt 6 kit.
Needs an OpenGL 3.3 core capable GPU/driver.
Uses the Qt SVG module (Qt Svg, installed with Qt by default) for diagram export.

NOTE: resources.qrc and the icons/ folder must stay next to CMakeLists.txt
(they hold the dropdown arrows and the checkbox tick used by the theme).

Translation: after changing texts in the code, build the "update_translations"
target to add the new texts to KnotTheory_sq_AL.ts, then translate them
(Qt Linguist or any text editor).

Windows installer (Inno Setup 6.7 or newer: winget install JRSoftware.InnoSetup)

  powershell -ExecutionPolicy Bypass -File installer\build_installer.ps1

  Makes a Release build, collects the Qt files with windeployqt and writes
  installer\output\AKSIOMA-Knots-<version>-Setup.exe (the version from
  CMakeLists.txt). Change the Qt paths with -QtDir / -QtTools if needed.
  The installer is in English and Albanian (installer\Albanian.isl), and
  installs the program, the user manuals (..\Manual) and the .aknot file type.
  Its pictures are made from icons\aksioma_logo.png by installer\make_images.py.
