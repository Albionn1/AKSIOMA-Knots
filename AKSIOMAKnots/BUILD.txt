Build (Qt 6.12 with MinGW 13.1 is what is used and tested; main.cpp touches one
private Qt interface, so another Qt version can stop it compiling. The Qt SVG and
Qt Linguist modules must be installed.)

  cmake -S . -B build -DCMAKE_PREFIX_PATH=<path to Qt, e.g. C:/Qt/6.12.0/mingw_64>
  cmake --build build --config Release
  run build/AKSIOMAKnots   (Windows: build/Release/AKSIOMAKnots.exe, run windeployqt first)

Or: open CMakeLists.txt in Qt Creator and pick a Qt 6 kit.
Needs an OpenGL 3.3 core capable GPU/driver.

The 3D renderer is AKSIOMA Engine, a project of its own. CMake fetches the
release this app is made for (AKSIOMA_ENGINE_TAG, now v0.1.1) from GitHub once,
so every build gets the same engine. To work on the engine and the app
together, point at a working copy with -DAKSIOMA_ENGINE_DIR=<folder> or the
AKSIOMA_ENGINE_DIR environment variable (cmake/AksiomaEngine.cmake).

Shaders: the engine's are in its shaders/ folder, this app's (the toy train and
its steam) in shaders/. To work on them without rebuilding, run with
AKSIOMA_SHADER_DIR=<AKSIOMA Engine>/shaders and/or
AKSIOMA_KNOTS_SHADER_DIR=<this folder>/shaders: they are read from disk, and
saving one redraws the view with it at once.
Uses the Qt SVG module (Qt Svg, installed with Qt by default) for diagram export.

NOTE: resources.qrc and the icons/ folder must stay next to CMakeLists.txt
(they hold the dropdown arrows and the checkbox tick used by the theme).

Headless checks: every folder in tools/ with a CMakeLists.txt builds on its own
(cmake -S tools/<name> -B <somewhere> -DCMAKE_PREFIX_PATH=<path to Qt>). They need
no screen: window_test runs the real main window hidden, with its own settings.
math_audit is the acceptance test of the mathematics: after anything that touches
curves, every line it prints must say ok.

Translation: after changing texts in the code, build the "update_translations"
target to add the new texts to KnotTheory_sq_AL.ts, then translate them
(Qt Linguist or any text editor).

Windows installer (Inno Setup 6.7 or newer: winget install JRSoftware.InnoSetup)

  powershell -ExecutionPolicy Bypass -File installer\build_installer.ps1

  Makes a Release build, collects the Qt files with windeployqt and writes
  installer\output\AKSIOMA-Knots-<version>-Setup.exe (the version from
  CMakeLists.txt). Change the Qt paths with -QtDir / -QtTools if needed.
  The installer is in English and Albanian (installer\Albanian.isl), and
  installs the program, the user manuals (..\Manual) and the .aknot file type.
  Its pictures are made from icons\aksioma_logo.png by installer\make_images.py.
